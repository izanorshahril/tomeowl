**Type:** wayfinder:research

## Question

Which available inputs demonstrate both the requested machine-level project view and a connected literature-shaped review without creating unsupported claims?

## Resolution

Use bounded selected documentation from all discovered eligible project directories under the user-requested local development root, plus this project's active research notes and relevant specifications.
Keep generated inventory records and derived artifacts in local data, with discovery/inclusion/skip counts and declared deterministic role classification.
Inventory records describe observed project/document structure; they are not application-health signals or dependency assertions.
Explicit Markdown references and shared exact citation URLs can form inspectable links under named rules, while URL-only citations remain clearly unfetched metadata.

The research corpus demonstrates passage inspection and inter-document references.
It does not complete bibliography import, duplicate/version screening, claim/method matrices, or paper full-text extraction.
Those requirements remain the separately staged literature gate.
Public source and tests use self-authored or permitted fixtures instead of embedding unrelated local project content.
